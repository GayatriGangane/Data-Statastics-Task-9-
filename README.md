# Python Data Processing and Summary Statistics

## Project Overview

This project was developed as part of the Veda Technology AI & ML Track - Task 9.

The objective of the project is to process structured student records using Python and generate useful summary statistics. The project demonstrates the use of lists, dictionaries, functions, loops, conditional statements, list comprehensions, and basic statistical calculations.

## Objective

The main objectives of this project are:

- Store structured records using Python dictionaries.
- Process a collection of records.
- Calculate useful summary statistics.
- Categorize student performance.
- Identify top-performing students.
- Generate department-wise statistics.
- Filter records based on marks.
- Display processed records in a structured format.

## Technologies Used

- Python
- Jupyter Notebook

## Dataset

The project uses a sample student dataset containing:

- Student ID
- Student Name
- Age
- Marks
- Department

The dataset contains 10 student records.

## Python Concepts Used

The following Python concepts are demonstrated:

- Lists
- Dictionaries
- Functions
- For loops

- List comprehensions
- Dictionary operations
- Data filtering
- Statistical calculations
- String formatting

## Processing Performed

The project performs the following operations:

1. Stores student records.
2. Displays the original records.
3. Calculates total number of students.
4. Calculates average marks.
5. Finds highest marks.
6. Finds lowest marks.
7. Calculates average age.
8. Calculates pass percentage.
9. Assigns performance categories.
10. Identifies top-performing students.
11. Calculates department-wise statistics.
12. Counts students according to performance.
13. Filters students scoring 85 or above.

## Performance Categories

The students are categorized using the following rules:

| Marks | Category |
|------|----------|
| 90 or above | Excellent |
| 80-89 | Very Good |
| 70-79 | Good |
| 60-69 | Average |
| Below 60 | Needs Improvement |

## Output

The program generates:

- Original student records
- Processed student records
- Summary statistics
- Top performers
- Department-wise statistics
- Performance category counts
- Filtered student records
